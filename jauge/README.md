la session réservée `jauge-<n>` du workflow Claw Web les note et range le résultat sur la
branche `claw-web-fichiers` du dépôt des sessions (`jauge/<n>.json`).

- `kit/` : l'appli d'exemple du kit d'appli de Claw, telle quelle (doit atteindre la barre) ;
- `claude/` : l'appli de budget faite par Claude (dépôt budget_claude), la référence ;
- `claw39/` : l'appli de Claw à la fin de l'essai réel #39 (deux passages).

Chaque dossier garde la demande de l'utilisateur dans `demande.txt`.
